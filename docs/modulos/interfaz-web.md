# Módulo Interfaz Web (MVC)

Capa de presentación basada en ASP.NET Core MVC para vistas administrativas.

---

## 1. Responsabilidades

* Renderizado de vistas HTML/Razor para la interacción del usuario.
* Manejo de rutas web por defecto (`{controller=Licitaciones}/{action=Index}`).
* Gestión de recursos estáticos (`wwwroot`).
